# GuideAnts v1.0.0 – Draft Release Notes

**A first-class local AI stack with per-model services, resilient streaming, and a polished chat experience.**

## What's new since v0.11

- **Model-specific local services** (#153) – Individual sandbox endpoints now route to specific model backends by model ID, enabling simultaneous use of multiple cloud providers and local models split across machines.
- **Sandbox JWT clock skew tolerance** (#152) – Allows 30s NTP drift on JWT validation so transient host time steps no longer 401 a just-minted token.
- **Live media cache revisions** (#152) – New shared `authenticatedMediaCache` keyed by URL + per-notebook revision fixes image flicker and stale thumbnails when turns re-emit files.
- **Hugging Face custom install completion** (#152) – HF model installs now report proper completion status instead of hanging indefinitely.
- **Tool result pending status fix** (#150) – External app tool results no longer get stuck in a "pending" state; fixes `build_webapi_ui.sh` from recreating arm64 images on non-arm64 machines.

## Improvements

- **Chat readiness gate at send** (#146) – Dropped the redundant `checkRuntimeStatus` preflight round-trip that caused multi-second send delays. Not-ready rejections now use a 409 with rollback semantics: draft + chips restored when no turn was persisted, clean slate when it was.
- **Reasoning choices as JSON** (#149) – Model settings reasoning field is now stored in the same JSON format as all other fields for consistency.
- **Host-SSH skill: macOS support** (#148) – The `host-ssh` sample skill now works on macOS in addition to Windows/Linux.

## What's under the hood

This release ships a full set of GHCR images pinned by digest (WebAPI UI slim & MSSQL, AI variants for CPU/CUDA13/ROCm/Vulkan, PlantUML, MSSQL FTS, SearXNG) with an installer zip that locks exact digests and offers update prompts when `:main` moves ahead.
