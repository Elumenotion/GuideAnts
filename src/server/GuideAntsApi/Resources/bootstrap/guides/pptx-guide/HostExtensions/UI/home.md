# Welcome to the Presentation Guide
## Purpose
- Create, edit, and export slide shows with images by orchestrating specialized assistants.
- Go from idea to polished .pptx while keeping media and content organized.
## Meet your assistant crew
- Slide Shows: create, edit, list, and export presentations; show markdown; generate .pptx.
- Media Creator: generate or edit images, video, and audio for slides.
- Diagrams: produce professional PlantUML diagrams as images.
- Code Executor: create and save text/code files (like .md guides) and perform transformations.
- Memory Explorer: surface existing notes/content from your workspace for reuse in slides.
- Search: pull current, external facts or inspiration when needed.
## Quick start: zero to .pptx
```
List my slide shows
Create a presentation called Project Overview
Add a title slide with 'Welcome'
Add a bullet slide with 'Agenda' and bullets 'Intro, Demo, Q&A'
Add a slide with this image: process_flow.png
Show the presentation's md
Create the presentation
```
## Create or open a presentation
- List existing shows: "List my slide shows"
- Start new: "Create a presentation called Home Wine"
- Open for editing: "Open the presentation Home Wine"
## Add and edit slides
- Title slide: "Add a title slide with 'Starting Home Fruit Wine'"
- Bullet slide: "Add a bullet slide with 'Steps' and bullets 'Sanitize, Ferment, Bottle'"
- Image slide (workspace file): "Add a slide with this image: drone_hobby_overview.png"
- Reorder slides: "Move slide 2 before slide 1"
- Remove a slide: "Delete slide 3"
## Work with media
- Use existing images:
- "Add a slide with this image: sanitation_safety.png"
- "Add a slide with this image: process_flow.png"
- Create a new diagram (Diagrams):
- "Generate Electron update workflow diagram" → use the returned image (e.g., electron_worflow.png)
- Edit or create media (Media Creator):
- "Change eye color in portrait.png to red"
- "Create a video from diagram.png with zoom effect"
- Tip: reference exact filenames (e.g., process_flow.png, sanitation_safety.png, drone_hobby_overview.png)
## Reuse existing content
- Summarize notes with Memory Explorer: "Summarize my notes from last week"
- Turn results into slides: "Add a bullet slide with 'Key Findings' and bullets '…'"
## View and export
- Preview the deck structure: "Show the presentation's md"
- Export to PowerPoint: "Create the presentation"

## Tips and troubleshooting
- Image missing: verify the filename exactly (examples: process_flow.png, sanitation_safety.png, drone_hobby_overview.png).
- Edits not applied: ensure you opened the correct presentation before editing.
- Formatting looks off: "Show the presentation's md" to validate structure before export.
- Need inspiration or up-to-date facts: use Search, then convert results to slide bullets or request relevant diagrams/images.
- Complex visuals: prefer Diagrams for professional PlantUML outputs.
