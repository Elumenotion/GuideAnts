# Deck outline template

- **Opening** — hook and agenda (1 slide)
- **Context** — problem or opportunity (1–2 slides)
- **Approach** — your recommendation or story arc (2–4 slides)
- **Evidence** — data, examples, or demos (as needed)
- **Close** — summary, next steps, Q&A (1 slide)

Keep one main idea per slide. Prefer short titles and scannable bullets.
