## What is a Project?

A **Project** is the main container for all your work on a specific initiative, topic, or team. Within each project, you can create and manage:

- **Notebooks** – Organized workspaces for tasks, research, or guided workflows.
- **Files** – Documents, images, videos, and other resources to use or produce in your work.
- **Collaborators** – Your collaborators, with controlled access and roles.

---

## Navigating the Project

### 📒 Notebooks

- Find your notebooks in the left sidebar.
- Notebooks help you structure work into distinct areas (like research, planning, or content creation).
- Each notebook can have conversations, tasks, and its own set of files.
- Start a new notebook with the **New Notebook** button.

### 📁 Files

- All project files are managed in the Files section.
- Upload files from your computer or move files in and out of notebooks.
- Preview, download, version history, and actions are available for each file.
- Set a file as the project homepage or create a new notebook directly from a file.

### 👥 Collaborators

- View and manage your project’s collaborators.
- Invite others by email and assign them as **Contributors** (can edit) or **Readers** (can view).
- Project owners oversee access, usage, and billing.
